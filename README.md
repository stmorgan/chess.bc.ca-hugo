# README.md

This project is the result of a migration of the old PHP-based BC Chess Federation Website to one based on Hugo. Netlify is used to build the site after commits to GitHub and DecapCMS is used to create forms for content editors to manage the content. 

The migration was done largely by Claude AI. If you'd like to recreate a similar site for your organization, I'd recommend using Claude Code and directing it to read the files CLAUD.md and PROJECTPLAN.md. Once it's built the scaffolding, you can direct it make any necessary changes to suit your organization. 

See the Technical Report in the Docs directory for notes on architecture and maintenance.
